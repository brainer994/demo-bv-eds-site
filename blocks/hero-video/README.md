# hero-video

Custom **hero** block. Purpose: hero-video.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: row 1 = background image plus an optional link to an .mp4 video (same or second cell); row 2 = H1, intro paragraph, CTA links (bold = primary, italic = secondary), and a bulleted list where each item is a link with a bold title followed by a short description (rendered as platform tiles).
